# Phase 2 — Classical machine learning

**Weeks 6–10** · `uv sync --group ml`

Understand how models learn, how to evaluate them honestly, and when simple models win.

## Checklist

- [ ] [Machine Learning Specialization](https://www.coursera.org/specializations/machine-learning-introduction), courses 1–2 (Andrew Ng)
- [ ] [Kaggle Learn: Intro + Intermediate ML](https://www.kaggle.com/learn/intro-to-machine-learning)
- [ ] [scikit-learn user guide](https://scikit-learn.org/stable/user_guide.html): pipelines, CV, metrics
- [ ] Explain to each other: bias/variance, overfitting, data leakage, precision/recall
- [ ] **Build:** Kaggle Titanic, then House Prices — compare at least three models

## Ship

Kaggle submission plus a README report comparing models, with the leakage traps you avoided.
